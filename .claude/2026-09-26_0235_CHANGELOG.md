## Phase 4 design amendment (docs only — no code changes)

Added a "Phase 4 amendment" section to
`docs/superpowers/specs/2026-09-11-vocalis-design.md`, recording the
design decisions the user approved for the Document Reader feature
(Ctrl+Alt+D), reached via `superpowers:brainstorming` (architectural path).

### What changed and why

- **Voice engine:** Document Reader will reuse Qwen3-TTS ("Ryan") with
  Piper as fallback — the same pair already built and proven in Phase 3 —
  instead of the originally planned `fish-speech-1.5`. Reason: nothing new
  to install, no non-commercial license restriction, and one fewer place
  a dependency conflict (like the real `onnxruntime`/`onnxruntime-gpu`
  clash hit during the Phase 3 merge) could happen.
- **Popup:** a real PySide6 (Qt6) window (Open file / paste text / Read /
  Pause-Resume / Stop / progress), deliberately brought forward from
  Phase 6 rather than built twice.
- **Controls:** Stop plus Pause/Resume for this phase; paragraph skip/seek
  deferred (YAGNI).
- **Architecture:** the daemon's main thread will run the Qt event loop
  in place of today's blocking wait, with hotkey threads reaching the UI
  only through Qt signals — no second process.
- **One reading at a time:** a new small coordinator makes Quick Reader
  and Document Reader mutually exclusive.
- Corrected stale references to `fish-speech-1.5` in the Product Summary
  table, the Risks list, the Architecture engine-wrappers bullet, and the
  Tech Stack list, each pointing at the new amendment.
