## What was added

Vocalis gained the three pieces of code a background `systemd --user`
service needs to run safely, plus a unit-file template — but **nothing
in this stage installs, enables, starts, or sends a real signal to a
real systemd service.** That is Stage 3's job (the installer).

1. **A true single-instance guard** (`src/vocalis/daemon.py`). Before
   this stage, `VocalisDaemon.start()` deleted any existing socket file
   unconditionally, which could delete a *second real instance's* live
   socket out from under it. It now probes the file first
   (connect-before-delete) and tells apart three outcomes: genuinely
   **alive** (refuse to start, no notification), genuinely **stale**
   (delete it, as before), or **ambiguous** (treated as stale, so an
   inconclusive probe never blocks startup).
2. **Non-fatal startup checks** (`src/vocalis/startup_checks.py`, new
   file). Four independent checks — the Parakeet dictation model, the
   Qwen3-TTS voice model, `ydotoold`'s socket, and the OCR capture tools
   (`tesseract`/`xclip`) — each returning a message or `None`, run once
   at the top of `main()` and reported through the existing `Notifier`.
   None of them can stop Vocalis from starting, even if one itself
   raises.
3. **Graceful `SIGTERM` handling** (`src/vocalis/cli.py`). `systemctl
   stop`/`restart` sends `SIGTERM`; `main()` now handles it exactly like
   `SIGINT` (Ctrl+C) — same `app.quit()` lambda, same clean shutdown,
   both handlers restored on exit.
4. **A systemd unit-file template** (`packaging/systemd/vocalis.service`,
   `packaging/systemd/README.md`, new). `Restart=on-failure` +
   `RestartSec=3` + `StartLimitBurst=5`/`StartLimitIntervalSec=60`;
   `WantedBy=xdg-desktop-autostart.target` (not `default.target`, since
   this account has `Linger=yes`); `After=`/`Wants=` on the three
   PipeWire user services. Two placeholders (`__VOCALIS_EXEC__`,
   `__VOCALIS_WORKDIR__`) are filled in by Stage 3's installer, not by
   hand.
5. **Documentation** (this task): `docs/user-docs.md`,
   `docs/architecture.md`, `docs/workflow.md`, `docs/file-purpose.md`,
   `docs/folder-structure.md`, `docs/developer-docs.md`, and a
   "deviations and findings" amendment to the spec.
