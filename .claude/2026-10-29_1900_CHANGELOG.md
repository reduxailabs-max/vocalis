# Stage 7 — Red-and-black UI, tabbed Settings, reading highlight: change log

Branch `worktree-stage7-ui-highlight`.

## Summary

Vocalis now has one dark red-and-black look in every window. Settings is
split into five tabs, the floating card can be dragged, and the Document
Reader shows the text it reads and highlights the piece being heard.

## Files changed

- New: `src/vocalis/ui/theme.py`
- Changed: `src/vocalis/ui/tray.py`, `floating_widget.py`,
  `settings_window.py`, `doc_popup.py`; `src/vocalis/features/doc_reader.py`;
  `src/vocalis/settings.py`; `src/vocalis/cli.py`
- Docs: `docs/architecture.md`, `user-docs.md`, `file-purpose.md`,
  `workflow.md`, `algorithms.md`

## User-visible changes

- Tray icon: grey dot idle, bright red dot listening, red ring with white
  centre reading.
- Floating card is draggable; its spot is kept until Vocalis quits.
- Settings has tabs: General, Voice & Engine, Performance, Shortcuts, Model files.
- New controls: voice idle-unload time and model file locations.
- Changed model locations are checked on Save; a missing one is refused.
- Changing model locations or idle time needs a restart (the Saved message says so).
- Document Reader shows the cleaned-up text and highlights the current piece.

## Performance impact

Negligible: stylesheet parsed once; one selection update per piece; no new
dependencies.

## Rollback

Revert the Stage 7 merge commit range. No config format change — the only
values the new Settings controls write are the existing
`model_idle_timeout_seconds` and existing model path fields, so older
Vocalis versions read the file unchanged.
