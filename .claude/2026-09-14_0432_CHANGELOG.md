# Changelog — 2026-09-14

## Vocalis Phase 2, Task 5: Desktop Notifier (pop-up messages via notify-send)

Added the small piece of Vocalis that will later show pop-up desktop
messages, like "Listening..." or "Done", so the user knows what the app
is doing without having to look at a terminal window. Nothing else in the
app uses it yet — this task only builds and tests the notifier itself.
The feature that will actually use it (the dictation feature, Task 6) and
the part that switches it on (Task 7) come in later tasks.

**Added:**
- `vocalis.notify.Notifier` — the class that sends pop-up notifications.
  - `notify(title, message="")` shows a pop-up with a title and an
    optional message, using a helper program called `notify-send` (the
    standard Linux tool for desktop pop-ups).
  - If notifications are turned off in settings (`enabled=False`), calling
    `notify()` does absolutely nothing — it does not even try to run
    `notify-send`. This keeps things quiet for anyone who does not want
    pop-ups.
  - If `notify-send` is missing, broken, or takes too long, `notify()`
    quietly writes a warning to the log and moves on — it never crashes
    the app just because a pop-up could not be shown.
  - Like Task 4's text-typing feature, the actual call to `notify-send`
    goes through one small injectable "command runner" seam, so every
    automated test can pretend to run it without ever popping up a real
    notification on this machine.
- `tests/test_notify.py` — 4 automated tests using a fake pretend command
  runner: notifications turned off send nothing at all, a normal
  notification includes both the title and the message, a notification
  with no message only sends the title, and a failure from `notify-send`
  never crashes the program.
