# Stage 8 — Installer setup window: change log

Branch `worktree-stage8-installer-wizard`.

## Summary

The installer now has a friendly setup window. It also works on computers
without an NVIDIA graphics card.

## What changed (in plain words)

- The installer is split into three parts: prepare, models, finish. You can
  run one part with `--phase`, or everything in the terminal with
  `--no-wizard`.
- After the prepare part, a five-page **Vocalis setup** window opens if you
  have a screen: Welcome, What we found, Installing, Check your microphone,
  Finishing up. At the end Vocalis Settings opens.
- No NVIDIA driver is no longer an error. The installer prints a note, uses
  the processor-only speech runtime, and skips the big Qwen3-TTS voice. It
  also skips it when the graphics card has less than 4096 MB of memory.
- If the window cannot open, the installer finishes in the terminal by
  itself.
- The microphone test only warns; it never blocks Finish.
- Stopping the window stops the whole running install. Nothing is undone;
  run the installer again to finish. The window keeps a log at
  `~/.local/share/vocalis/install.log`.
- Docs fixed: `architecture.md` no longer calls the GPU check a "hard gate".

## Why

Beginners should not have to read terminal output, and PCs without an
NVIDIA card should still be able to install Vocalis.

## Files

- New: `src/vocalis/installer/` (`plan`, `progress`, `runner`, `mic_test`,
  `wizard`, `wizard_pages`, `app`), five `tests/test_installer_*.py` files.
- Changed: `packaging/installer/install.sh`, `lib/preflight.sh`,
  `lib/pyenv.sh`, `lib/fetch_models.py`, `pyproject.toml`, the `bats` tests.
- Docs: `packaging/installer/README.md`, `docs/user-docs.md`,
  `architecture.md`, `file-purpose.md`, `folder-structure.md`, `workflow.md`.

## How to roll back

Revert the Stage 8 commits (`git log main..worktree-stage8-installer-wizard`
lists them, then `git revert` them). The old terminal install is also
still available any time with `bash install.sh --no-wizard`.

## Still to check on real PCs (by the user)

Never on the NTFS development drive. Please try:

1. A fresh user account.
2. A PC with no NVIDIA graphics card.
3. The network unplugged during the model download (then Try again).
4. A muted microphone (should show a warning only).
