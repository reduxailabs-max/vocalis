# Changelog 2026-11-11 — Stage 9: resumable, fast model downloads

## What changed
- New `src/vocalis/installer/downloader.py`: parallel (4 connections), chunked
  (16 MiB, HTTP Range), resumable (`*.part` + `*.part.json`), retrying
  (8 tries, backoff 1–30 s), verified (size + SHA-256) downloads; space reserved
  up front; stop keeps partial files.
- New `src/vocalis/installer/download_progress.py`: speed meter, size/speed/time
  formatting (B, KB, MB, GB, /s), `PROGRESS` line and live terminal bar.
- `packaging/installer/lib/fetch_models.py` rewritten as a list builder: sizes
  and checksums from Hugging Face, Qwen3 pinned to a commit, Kokoro wrong-size
  files re-fetched, Piper program archive added, free-disk check, total size note.
  Everything present means no network use.
- `install.sh`/`models.sh`: Piper archive fetched resumably by the downloader and
  unpacked afterwards; curl fallback now resumes and retries.
- `uninstall.sh --purge` also removes `~/.cache/vocalis/downloads`.
- Setup window: `progress.py` parses `PROGRESS` lines; the install page shows a
  real bar and "x of y · speed · time left"; progress lines are kept out of the log.
- Fixed a stale bats expectation (reworded wizard hint) from Stage 8.

## Why
The old download showed no real progress in the setup window, could not resume
Kokoro or Piper, and lost work on any hiccup.

## Rollback
Revert the Stage 9 commits; `install.run` from before still works (old behaviour).

## Verification
1098 pytest passed (96.13% coverage), mypy strict clean (133 files), 110 bats ok,
shellcheck clean. Real-internet behaviour is for the user's own install test.
