# Changelog — 2026-09-19 (Phase 2 fix round)

## Vocalis Phase 2: fix round — final review findings

The final whole-branch review of Phase 2 found two real bugs that only
show up with a real microphone/keyboard (which is why no automated test
in Tasks 1-8 caught them). Both are fixed here with new regression tests
that reproduce each bug's class of failure before fixing it.

**Fixed:**
- `vocalis.audio.capture.MicRecorder._stop_stream_only()` held its lock
  across the blocking `stream.stop()`/`.close()` calls, which deadlocked
  against the real sounddevice audio callback thread (which needs the
  same lock) on every single dictation's stop path. Fixed by swapping out
  the stream reference under the lock, then calling the blocking methods
  outside it.
- `vocalis.hotkeys.numlock.NumlockListener._watch_device()` let any
  exception from an `on_press`/`on_release` callback escape the read
  loop, permanently killing that device's watcher thread — silently
  disabling the NUMLOCK hotkey for the rest of the process with no
  user-facing notification. Fixed by catching exceptions around just the
  two callback invocations, so the read loop itself is now robust
  regardless of what any callback does.

**Not changed:** `ModelManager`, `DictationFeature`, CLI/config wiring,
docs, `old/`. Both fixes are narrowly scoped to the two files above.

**Rollback:** revert this commit; both fixes are isolated, mechanical
lock/exception-handling changes with no behavioral change to the happy
path (all pre-existing tests still pass unchanged).
