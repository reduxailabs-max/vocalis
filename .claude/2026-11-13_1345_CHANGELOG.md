# Changelog — Stage 10: Qwen3-TTS becomes an optional add-on (2026-11-13)

## Why
Qwen3-TTS needs a strong graphics card and about 8 GB of PyTorch/CUDA helper
programs plus a 2.4 GB model, and it sounded worse than Kokoro on the user's
PC. The user asked to make it optional: chosen at install time, and added or
removed later from Settings.

## What changed (plain English)
- The default install no longer contains Qwen3-TTS. The setup window has an
  unticked box "Also install Qwen3-TTS (optional extra voice, about 8 GB more)".
  In the terminal the same choice is `--with-qwen3`.
- Settings → Voice & Engine has a new "Qwen3-TTS (optional extra voice)" box
  with the status and **Download and install** / **Remove** buttons. They show
  the same progress bar, speed and time left as the setup window, and Stop
  keeps partial downloads.
- Removing Qwen3-TTS deletes its voice files and exactly the helper programs
  that adding it installed (the installer saves a package list first).
- Without Qwen3-TTS, Automatic never picks it, a saved "Qwen3-TTS" choice falls
  back to Kokoro, and its entries in the voice lists are greyed out.
- The app starts without PyTorch; the graphics card is then read with
  `nvidia-smi`.
