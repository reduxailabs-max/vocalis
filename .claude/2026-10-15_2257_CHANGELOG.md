## Self-review notes

- `desktop_install_launcher` quotes the exec path before sed-escaping it, so a `$HOME` with spaces still produces a correctly quoted `Exec=` line (covered by its own test).
- The function is atomic: it writes to a `mktemp`-created temp file in the target directory and only `mv -f`s it into place on success; any failure (missing template, failed `chmod`, failed `mv`) removes the temp file and returns non-zero, leaving an existing launcher completely untouched (covered by its own test, which also checks no stray temp file is left in the directory).
- A failing `desktop_install_launcher` call in `install.sh` is caught with `||` and only prints a note — it can never fail the whole install, since the tray icon and `vocalis --settings` already work without a menu entry.
- All seven listed doc files plus the installer `README.md` were read in full before editing, and each new section matches that file's existing heading level and tone.
