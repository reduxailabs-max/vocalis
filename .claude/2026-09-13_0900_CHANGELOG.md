# Changelog — 2026-09-13

## Vocalis Phase 2, Task 1: Parakeet STT Engine Wrapper

Added the first real AI engine for Vocalis's dictation feature: a wrapper
around the existing local Parakeet TDT ONNX model, structured so
`ModelManager` (from Phase 0+1) can load/unload it under the single-GPU-
resident policy.

**Added:**
- `vocalis.engines` package (`src/vocalis/engines/__init__.py`).
- `vocalis.engines.parakeet.ParakeetSTT` — speech-to-text engine backed by
  the `onnx-asr` package, running the existing Voxtype Parakeet TDT ONNX
  model files (no re-download or conversion). Implements the
  `ModelEngine` protocol (`load()`, `unload()`, `is_loaded`) structurally,
  without changing `model_manager.py`. Defaults to the CUDA execution
  provider with a CPU fallback (`use_gpu=False`) for testing without a
  GPU.
- `vocalis.engines.parakeet.ParakeetLoadError` — raised when the model
  files are missing or loading otherwise fails, so callers get a specific,
  catchable failure mode instead of a bare exception.
- `_preload_cudnn()` — preloads the cuDNN shared libraries shipped inside
  the `nvidia-cudnn-cu12` pip package via `ctypes`, since `onnxruntime-gpu`
  does not bundle cuDNN and the CUDA execution provider cannot find it on
  the system library path otherwise.
- `tests/test_parakeet.py` — 6 tests: engine state before load, error
  handling for `transcribe()` before `load()`, `ParakeetLoadError` for a
  missing model directory, safe no-op `unload()` before `load()`, and two
  real-model round-trip tests (CPU and GPU) that run automatically on this
  machine (skipped elsewhere if the model files aren't present).
- New dependencies in `pyproject.toml`: `numpy`, `onnx-asr[gpu]`,
  `nvidia-cudnn-cu12`.

**Design notes / rulings honoured:**
- Reuses the exact local Parakeet model files at
  `~/.local/share/voxtype/models/parakeet-tdt-0.6b-v3-int8` — no download,
  no format conversion.
- The ~150MB CUDA/cuDNN process-lifetime residual (cuDNN context that
  stays resident even after `unload()`) is an accepted, intentional
  trade-off per the approved design — no subprocess isolation was added to
  eliminate it.
- Does not touch `vocalis.config` or `vocalis.cli` — `parakeet_model_dir`
  config and CLI wiring belong to Task 7, not this task.
- `old/` left untouched.

  'vocalis.engines.parakeet'` before the implementation existed.
