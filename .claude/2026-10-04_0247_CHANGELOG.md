# Phase 5 — OCR Reader change log

## What was added
Press **Ctrl+Alt+O**, drag (and resize) a box over text on screen, and the text is
copied to the clipboard and read aloud in the Document Reader window.

## New / changed code
- `src/vocalis/output/clipboard.py` — `ClipboardWriter` (xclip, output to DEVNULL).
- `src/vocalis/engines/tesseract_ocr.py` — `TesseractOCR`, `TesseractError` (CPU only, not via ModelManager).
- `src/vocalis/output/screen_capture.py` — `ScreenRegionCapture` (spectacle via private temp dir, maim, flameshot, slurp+grim; ASCII-only region check).
- `src/vocalis/features/doc_reader.py` — read-only `generation` property.
- `src/vocalis/ui/doc_popup.py` — `external_reading_started` signal and slot.
- `src/vocalis/features/ocr_reader.py` — `OcrReaderFeature`.
- `src/vocalis/cli.py` — `build_ocr_reader()`, Ctrl+Alt+O listener started last / stopped first.
- Docs updated: user-docs, architecture, workflow, file-purpose, folder-structure, developer-docs, design spec (Phase 5 deviations).

## Tests
268 -> 319 tests, 95.82% coverage, zero warnings, mypy strict clean (70 files).
The ocr/screen-capture/cli tests passed 10 runs in a row.
Task 7 hardening: stop-on-second-press never starts a capture; slurp region accepts only
ASCII digits (fix); clipboard runner DEVNULL handling pinned; CLI shutdown-order test now
includes the OCR listener first.

## Decisions
- Spectacle's picture goes through a private temp directory (deleted immediately); other tools keep the picture in memory (stdout, no temp file).
- Normalisation is done by `DocumentReaderFeature.read_text`; OCR only collapses whitespace.
- Popup is shown when an OCR reading starts so Pause/Stop are reachable.
- English only; resizing needs Spectacle (Flameshot may hang on some systems).

## Hands-on finding (2026-10-04)
Real-machine testing on the user's XFCE + X11 setup revealed **Flameshot hangs**:
`flameshot gui --raw` never shows its selection screen, and even `flameshot full --raw` hangs
with no output and no error, blocking Ctrl+Alt+O for up to 120 seconds. Testing confirmed:
- **Spectacle** works; region box can be resized by dragging edges/corners (user-approved).
- **Maim** works (draw once, no resize).
- **Flameshot** confirmed broken on this machine.

**Fix applied:** Tool order changed to spectacle (resizable, via temp directory) → maim →
flameshot (tried third; known to hang on this setup) → slurp+grim (Wayland fallback).
All tests (22 screen-capture tests + 305 others = 327 total) passing; loop tests (10x)
all green. Tool selection is determined once per call, first-installed-wins, no retry
after the tool was started.

## Smoke test (real tesseract + xclip, no screen)
OCR read "Hello OCR world"; clipboard write True; read back "vocalis-ocr-test"; clipboard restored.

## Final review
- Bug found by the final whole-branch review: pressing Ctrl+Alt+O while a document was being read made the new OCR reading fail ("Playback failed"), because the old chunk was still playing.
- Fix: `OcrReaderFeature` now stops any reading in progress (`reader.stop()`) before starting the OCR text. Covered by fake-reader tests and a real-DocumentReaderFeature regression test in `tests/test_doc_reader.py`.
- Two older OCR tests now cancel the capture so they still prove "the press itself stops nothing".
