# Changelog — 2026-09-13

## Vocalis Phase 2, Task 3: NUMLOCK push-to-talk key listener

Added the piece of Vocalis that watches the keyboard for the NUMLOCK key
being held down and let go. Later on, this will let a user hold NUMLOCK to
record their voice and let go to stop — like a walkie-talkie button. This
task only adds the "listening for the button" part; it does not yet record
audio or type text.

**Added:**
- `vocalis.hotkeys` — a new small package for keyboard-shortcut listeners.
- `vocalis.hotkeys.numlock.NumlockListener` — watches one or more keyboard
  devices in the background and calls an `on_press` function when NUMLOCK
  goes down and an `on_release` function when it comes back up. Ignores
  every other key and ignores the keyboard's own auto-repeat signal.
- `vocalis.hotkeys.numlock.list_numlock_capable_devices()` — finds the
  real keyboard devices on the computer that have a NUMLOCK key. This is
  the function later wired into the `vocalis` command-line tool.
- `evdev` added as a project dependency (the library used to read raw
  keyboard events on Linux).
- `tests/test_numlock.py` — 6 automated tests using a fake pretend
  keyboard, so the tests never touch the real keyboard.

**Important safety property:** this listener does NOT "grab" or block the
NUMLOCK key. That means the keyboard's own NumLock light and on/off state
keep working normally for every other program, exactly like before. This
was checked by hand on the real machine: pressing NUMLOCK still turned the
NumLock indicator on and off normally while the listener was running.

**Not yet implemented (future tasks):** nothing calls this listener yet;
that wiring happens in a later task that connects it to the actual
recording feature and the `vocalis` command-line tool.

**Rollback:** this change is additive only — it adds new files and one new
dependency line; nothing existing was modified or removed. Reverting is
`git revert` back to before this task's commit.
