# Changelog — 2026-09-18

## Vocalis Phase 2, Task 7: Wiring dictation into the real `vocalis` command

This task connects everything built in Tasks 1-6 to the actual `vocalis`
program you'd run on your computer. Before this task, all those pieces
(the speech-to-text engine, the microphone recorder, the NUMLOCK key
listener, the text typer, the pop-up notifier, and the "DictationFeature"
that ties them together) existed and were tested, but nothing actually
started them when you ran `vocalis`. Now it does.

**Changed:**
- `src/vocalis/config.py` — added a new setting,
  `engines.parakeet_model_dir`, which tells vocalis where to find the
  speech-to-text model files on disk. It defaults to the same folder the
  older Voxtype program already uses
  (`~/.local/share/voxtype/models/parakeet-tdt-0.6b-v3-int8`), so Phase 2
  reuses the model files you already have instead of downloading them
  again.
- `config/default_config.toml` — added the matching line for the setting
  above, so the reference config file stays in sync with the code's
  built-in defaults (a test checks this automatically).
- `src/vocalis/cli.py` — rewritten so that:
  - `build_daemon(...)` now expects to be *given* an already-built
    "ModelManager" (the shared GPU traffic-cop), instead of building its
    own. This changed on purpose, because the ModelManager now needs to
    be shared between the daemon and the new dictation feature — there
    can only be one, since it enforces "only one AI model in the GPU at a
    time."
  - A brand-new function, `build_dictation(...)`, builds the real
    speech-to-text engine, the real microphone recorder, the real text
    typer, the real pop-up notifier, and the real DictationFeature that
    ties them together — then wires a NUMLOCK key listener to it, so
    holding NUMLOCK down starts recording and letting go transcribes and
    types out what you said.
  - `main()` (what actually runs when you type `vocalis`) now starts
    *both* the background daemon *and* the NUMLOCK listener when the
    program launches, and cleanly stops both when you press Ctrl+C.
- `tests/test_config.py` — added one test proving the new
  `parakeet_model_dir` setting defaults to the right folder under your
  home directory.
- `tests/test_cli.py` — replaced entirely (as the plan required) with
  three tests: one proving `build_daemon` uses the ModelManager it was
  given rather than making its own, one proving `build_dictation` wires
  the speech engine to the configured model folder and connects the
  NUMLOCK listener to the right press/release callbacks, and one proving
  `main()` starts and cleanly stops everything on Ctrl+C (using fake
  stand-ins for the config file, socket location, and the real-hardware
  NUMLOCK device scanner, so this test runs safely without needing actual
  keyboard hardware).

microphone recorder, no NUMLOCK listener, no text typer, no pop-up
